# Exporting

TV Rename can be setup to automatically export files which summarise the status of your library.

<table data-header-hidden data-search="false"><thead><tr><th></th><th></th><th></th></tr></thead><tbody><tr><td><strong>Type</strong></td><td><strong>Formats</strong></td><td><strong>Description</strong></td></tr><tr><td>Show and Movie Lists</td><td>TXT, HTML</td><td>Whenever a show is added or removed from the library TV Rename will update the show list file. The HTML version is a pretty output designed to be printed and viewable by users to help decide what to watch</td></tr><tr><td>Missing Episodes or Movies</td><td>XML, CSV</td><td>Whenever a full scan is executed TV Rename outputs details of all missing episodes.</td></tr><tr><td>When to Watch / Schedule</td><td>RSS, XML, iCal, TXT</td><td>Details all the upcoming episodes so that you know what episodes are going to air soon. Output whenever information from <a href="http://thetvdb.com/">The TVDB</a> about airdates is updated.</td></tr><tr><td>Renamed files</td><td>XML</td><td>For each scan TV Rename can provide a summary of all renamed files.</td></tr><tr><td>Copied and Moved files</td><td>XML</td><td>For each scan TV Rename can provide a summary of all moved/copied files.</td></tr><tr><td>Recent Playlists</td><td>M3U/8, WPL, ASX, XSPF</td><td>A playlist file of recently aired shows to be cued up in your favourite media player</td></tr></tbody></table>
