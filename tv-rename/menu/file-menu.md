# File Menu

## Export

Runs the configured exporters (see [exporters](../guides/features/exporting.md)). Either for all shows/movies, or just for the currently filtered ones.

## Save

Saves all setttings, the current caches of the downloaded movie data. See [configuration ](../technical/logs-and-configuration.md)for full details.

{% hint style="success" %}
It is **strongly** advised to turn on 'Auto Save on Exit' in the [preferences](preferences.md#the-general-tab)
{% endhint %}
