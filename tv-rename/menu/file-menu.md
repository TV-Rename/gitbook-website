# File Menu

## Export

**File > Export** (Ctrl+E) runs the exporters you have set up (see [Exporting](../guides/features/exporting.md)) for all of your shows and movies.

**File > Export Filtered** runs them for only the shows and movies that match the filter you have set with the `Filter` button on the **TV Shows** and **Movies** tabs.

## Save

**File > Save** (Ctrl+S) saves your settings, the show and movie information TV Rename has downloaded, and the layout of the main window. See [Logs & Configuration](../technical/logs-and-configuration.md#configuration-files) for where these are kept.

{% hint style="success" %}
It is **strongly** advised to turn on **Auto save on Exit** in the [preferences](preferences.md#the-general-tab)
{% endhint %}

## Exit

**File > Exit** (Alt+F4) closes TV Rename.

If you have changed any settings since they were last saved, and **Auto save on Exit** is not ticked, TV Rename asks "Your changes have not been saved. Do you wish to save before quitting?"

* `Yes` saves your settings, then closes.
* `No` closes without saving your settings.
* `Cancel` keeps TV Rename open.

With **Auto save on Exit** ticked, your settings are saved without asking. Either way, TV Rename also saves the downloaded show and movie information and the window layout as it closes.
